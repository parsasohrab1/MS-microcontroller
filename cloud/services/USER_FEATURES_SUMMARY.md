## 🚀 استفاده سریع

### اپلیکیشن موبایل:

```bash
cd mobile-app
npm install
npm run ios  # یا npm run android
```

### پورتال وب:

```bash
cd web-portal
npm install
npm run dev
```

### گزارش‌گیری:

```python
from cloud.services.reporting_service.app.report_generator import get_report_generator, ReportData, ReportType, ReportFormat

generator = get_report_generator()

report_data = ReportData(
    patient_id="patient_123",
    period_start=datetime.now() - timedelta(days=7),
    period_end=datetime.now(),
    report_type=ReportType.WEEKLY,
    # ... سایر فیلدها
)

pdf_path = generator.generate_report(report_data, ReportFormat.PDF)
```
